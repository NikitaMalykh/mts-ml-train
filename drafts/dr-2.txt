Деревья решений.
Сегодня посмотрим про вариант, основанный на кросс-энтропии.
Движемся от корня (train_shape[0] = n).
<рисунок.
Листы дерева - группа m.
Делим каждую вершину на 2 части - left, right.
События в каждом листе однородные.
Энтропия E = -SUM[i=1_C] (p_i * logp_i)
от этого перейдём к Information Gain [0, 1]

Связь с one hot encoding.
Построение дерева в depth first (ограничения могут быть по max-depth, max-leaf).
Алгоритм точно улавливает нелинейные зависимости, паттерны:
w0 + SUM(w_i * x_i) - связь с pytorch

Далее про банки, выручки и продажи. Оценки выборки обучений по сравнению с прошлым годом.

Как усилить одно дерево? Создать ансамбль.

----------------------------------------------------------------

Ансамбли деревьев.
Идея - давать из всех строк 50% на одно дерево, другие 50% - другому узлу. Процент определяется через гиперпараметры.
Будем показывать не только строки, но и % фичей. На каждый слой/узел ляжет n процентов

Bagging (Bootstrap Aggregating)
Берем данные по всем независимо построенным деревьям, агрегируем -> получаем усредненные данные.
Разложение ошибки модели на смещение, разброс, неснижаемый шум: CW = bias + vav + ire

----------------------------------------------------------------

Градиентный бустинг.
Создаёт зависимости между деревьями ансамбля.
Поведении функции в окрестности точки, производная. Важность 2-й производной.
Градиент - вектор с частными производными <формула>
Он укажет направление к минимуму.
Понятие learning rate.
Gradient descent <фото/что это>: горы, долины, плато. Loss.

Перейдём к loss-функции. Производная по k-му параметру.
mse: l = (y - y_head)^2
y^ = x1*w1 + x2*w2
dh = y - y^
(dl/dh) * (dh / dy^) * (dy^ / dw1)
получили: 2(y - y^) * x - 1

В деревьях нельзя выйти на уровень веса. Работаем с пространственными занчениями функций.
x^2 -> реальный loss, mse

Для кросс-энтропии: производная = y^ - y
Градиенты - основа всего, что будет дальше.

Понятие логитов.
Градиент = [y^ - y, ...], n-train_shape.

Сигмоида.
y^ = (dl / сигмоида)  * ...
Гессиан - hess = [y^ * (1 - y^)]. Вторая производная по функции потерь. До сих пор решаем задачу от Майкрософт (см. выше).

Вариант инициализации данных в начале работы.
Пусть, первые логиты по всем наблюдениям равны 0. Тогда при переводе через ф-лу сигм. знач. равны 0.5
На 1-й итерации будет 2 уник. варианта в градиенте +0.5 или -0.5. В гессиане -0.25.

Рассмотрим задачу, связ. с доходом.
255 бинов. 50 млн уник. доходов.
Построим квантили по исх. данным. По каждому из бинов посчитаем SUM(grad) / SUM(hess).
Статистика будет пересчитываться перед каждым новым деревом.

То же работает и по категориальным параметрам. Маленькие параметры/характеристики в один бин.
Базирование на lightGBM.
xgboost, счёт бинов по гессиану.

Критерий сплита.
H(узла) - взвеш. энтропия детей узла -> берем макс. знач.

G^2 / (H_l + lyambda) + G_r^2 / (H_l + lyambda) - (G + Gr) ^ 2 / (H_l + H_r + lyambda) <может быть опечатка>
lyambda - L2-регуляризация
Пытаемся сгруппировать градиенты по знаку.
ф-ла G/(H+lyambda)
Learning rate будет общим для всех листов. Гессиан задаст, на сколько быстро следует идти в направление градиентаю


p - синоним y^
Цикл обучения по градиентам, деревьям.
